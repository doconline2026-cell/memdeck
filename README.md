## 📖 Giới thiệu / Introduction

**MemDeck** là plugin học ngoại ngữ dành cho **KOReader** (nền tảng đọc sách trên các thiết bị e-ink như Kindle, Kobo, PocketBook, Android...). Ứng dụng giúp bạn học từ vựng hiệu quả bằng flashcard kết hợp lặp lại ngắt quãng (SM-2), nhiều kiểu kiểm tra và một gia sư AI ngay trên máy đọc sách.

**MemDeck** is a language learning plugin for **KOReader** (an e-ink reading platform for Kindle, Kobo, PocketBook, Android...). It helps you learn vocabulary with flashcards and spaced repetition (SM-2), many test types and an AI tutor right on your e-reader.
